# DBATU PYQ Hub
A free, student-focused hub for organizing and finding Dr. Babasaheb Ambedkar Technological University (DBATU) previous-year question papers.
## Getting started
Requirements: Node.js 20.9 or newer and npm.
```bash
npm install
npm run dev
```
Open http://localhost:3000.
## Principles
- Keep the core project usable without paid services or paid APIs.
- Never commit credentials, tokens, private keys, or `.env` files.
- Only publish papers when sharing is permitted; include source and attribution where applicable.
The contribution link is a placeholder until a reviewed submission process is chosen.
