# Project guidance
- Use Next.js App Router with TypeScript.
- Keep the experience simple, responsive, accessible, and free to run locally.
- Prefer small components and clear names; avoid adding dependencies without a concrete need.
- Never add secrets or real credentials. Keep local environment files out of Git.
- Treat exam papers and metadata as untrusted input; validate data before rendering or storing it.
- Preserve source and attribution information for papers.
- Discuss a free alternative before adding paid services or APIs.
